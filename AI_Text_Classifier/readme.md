# Day 12: ⚖️ AI Text Classifier

A lightweight Machine Learning application that classifies text input into specific categories (Technical vs. Gaming/Casual) using traditional ML algorithms.

## 🚀 Features
- **Efficiency:** Runs instantly on CPU with zero latency.
- **Scikit-Learn Pipeline:** Uses TF-IDF Vectorization and Logistic Regression.
- **Real-time Prediction:** Classifies text as you type.

## 🛠️ Tech Stack
- **Python**
- **Scikit-learn** (Machine Learning)
- **Streamlit** (UI)
- **Pandas** (Data Handling)

## 📦 Setup & Run
1. Install dependencies:
   `pip install scikit-learn pandas streamlit`
2. Run the app:
   `streamlit run app.py`
